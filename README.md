# 平祿壽司 × Blogger Guide

部落客接待導覽互動式網頁，提供分店環境介紹、推薦拍攝餐點、影片腳本建議、合作注意事項與聯繫資訊。供現場人員、KOL 與合作部落客快速取得拍攝合作所需的完整資訊。

## 內容

- **品牌故事**：含品牌時間軸與五權／松竹／永順三家分店的環境照片導覽
- **選擇今日分店**：每家分店的位置、空間風格、飲料自助吧資訊、分店特色，與「推薦拍攝餐點」（新品上市 + 各分店限定品項）
- **必拍亮點清單**：餐點、空間、體驗三類重點，並可勾選追蹤進度
- **30 秒影片腳本建議**：分段提示開場、環境、餐點、收尾的拍攝邏輯
- **合作注意事項**：拍攝、內容、發文三類規範
- **社群與訂位連結**：官方 Instagram、Facebook、Inline 線上訂位

## 線上預覽

啟用 GitHub Pages 後，網址格式為：

```
https://<你的 GitHub 帳號>.github.io/heiroku-blogger-guide/
```

任何手機、平板、電腦只要瀏覽器可開啟即可使用。

## 檔案結構

```
.
├── index.html          # 主頁面（HTML + CSS + JavaScript 單檔）
├── README.md           # 本說明文件
└── assets/
    └── images/
        ├── logo/       # 品牌 Logo
        ├── stores/     # 三家分店環境照片
        └── menu/       # 推薦拍攝餐點圖片
            ├── new/      # 新品上市（三店共用）
            └── limited/  # 限定餐點（依分店分目錄）
```

## 技術

純前端：HTML5 + CSS3 + 原生 JavaScript，無第三方依賴。可直接以 `file://` 開啟，或部署於任何靜態網站平台（GitHub Pages、Netlify、Vercel、Cloudflare Pages 等）。
